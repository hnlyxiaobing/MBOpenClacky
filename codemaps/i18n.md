# i18n - 国际化 · 多语言翻译

> 路径: `lib/i18n/` · 2 文件（src=1, test=1）· 轻量国际化框架

## 入口函数

| 函数 | 文件 | 说明 |
|------|------|------|
| `t(locale, key)` | `i18n.mbt` | 翻译键值（返回对应语言文本，找不到则返回 key） |
| `t_with_params(locale, key, params)` | `i18n.mbt` | 带参数的翻译（`{name}` 占位符替换） |
| `resolve_locale(locale)` | `i18n.mbt` | 解析语言代码（不支持则回退 default_locale） |
| `is_supported(locale)` | `i18n.mbt` | 判断语言是否受支持 |

## 关键类型

- **常量** - `default_locale = "en"`、`supported_locales = ["en", "zh"]`
- 翻译表为内联 `Map[String, Map[String, String]]`（key -> locale -> text）

## 核心调用链

```
t("zh", "app.title")
  └─ translations.get("app.title")?.get("zh") ?? "app.title"
```

## 文件职责分组

| 文件 | 职责 |
|------|------|
| `i18n.mbt` | 翻译表、t/t_with_params/resolve_locale/is_supported |

## 外部依赖

- 无外部包依赖

## 风险点

1. **翻译表硬编码** - 所有翻译内联在源码中，新增语言需修改源码
2. **占位符格式** - `{name}` 简单替换，不支持复数/性别等复杂格式
