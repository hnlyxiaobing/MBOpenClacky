# 项目规则加载系统 · 启动 Spec (IDEA_DOC)

> **创建日期**: 2026-07-27  
> **状态**: 讨论中  
> **负责人**: 待定

## 核心目标

实现项目规则加载系统，支持从 `.clackyrules/AGENTS.md`、`CLAUDE.md`、`.cursorrules` 等文件加载项目规则并注入到系统提示中。Ruby 版本支持完整的规则发现和加载，MoonBit 版本仅有占位注释 "Phase 5+"。

## 关键能力

- 支持多种规则文件格式（`.clackyrules/AGENTS.md`、`CLAUDE.md`、`.cursorrules`）
- 自动发现项目根目录下的规则文件
- 将规则内容注入到系统提示
- 支持子项目规则发现
- 支持规则文件优先级

## 明确不做

- **不做规则编辑 UI**（原因：文件编辑即可）
- **不做规则验证**（原因：保持简单）
- **不做规则版本控制**（原因：Git 已支持）

## 关键决策（含为什么）

1. **决策 1**：使用 MoonBit 的文件系统 API 发现规则文件
   - **为什么**：MoonBit 标准库支持文件操作

2. **决策 2**：规则文件按优先级顺序加载
   - **为什么**：避免规则冲突

3. **决策 3**：规则内容注入到系统提示末尾
   - **为什么**：不影响主要系统提示内容
