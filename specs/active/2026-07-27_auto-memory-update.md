# 自动记忆更新系统 · 启动 Spec (IDEA_DOC)

> **创建日期**: 2026-07-27  
> **状态**: 讨论中  
> **负责人**: 待定

## 核心目标

实现自动记忆更新系统，在任务完成后通过 LLM 驱动的白名单记忆持久化。Ruby 版本支持 post-task subagent 自动更新记忆，MoonBit 版本仅有手动 memory tool。

## 关键能力

- 任务完成后自动触发记忆更新
- 使用 LLM 分析对话内容，提取值得记忆的信息
- 白名单机制，只记忆特定类型的信息
- 与现有 MemoryStore 集成
- 支持记忆去重和合并

## 明确不做

- **不做记忆编辑 UI**（原因：文件编辑即可）
- **不做记忆搜索**（原因：当前记忆量小）
- **不做记忆分类**（原因：保持简单）

## 关键决策（含为什么）

1. **决策 1**：使用 subagent 执行记忆更新
   - **为什么**：避免阻塞主 agent 流程

2. **决策 2**：使用 LLM 分析对话内容
   - **为什么**：智能提取值得记忆的信息

3. **决策 3**：白名单机制控制记忆类型
   - **避免**：避免记忆过多无用信息
