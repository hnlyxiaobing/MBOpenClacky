# Session 上下文注入 · 启动 Spec (IDEA_DOC)

> **创建日期**: 2026-07-27  
> **状态**: 讨论中  
> **负责人**: 待定

## 核心目标

实现 Session 上下文注入功能，在每次对话开始时注入当前日期、模型名称、操作系统等信息到系统提示中。Ruby 版本支持每日注入和模型切换时更新，MoonBit 版本完全缺失。

## 关键能力

- 注入当前日期（YYYY-MM-DD 格式）
- 注入当前模型名称
- 注入操作系统信息（WSL/Windows/Linux/macOS）
- 注入工作目录
- 在对话开始时自动注入
- 模型切换时更新注入

## 明确不做

- **不做自定义上下文字段**（原因：保持简单）
- **不做上下文持久化**（原因：每次对话重新注入）
- **不做上下文编辑 UI**（原因：系统自动注入）

## 关键决策（含为什么）

1. **决策 1**：在系统提示末尾追加上下文信息
   - **为什么**：不影响主要系统提示内容

2. **决策 2**：使用标准格式注入
   - **为什么**：便于模型理解和使用

3. **决策 3**：模型切换时重新注入
   - **为什么**：确保上下文信息是最新的
