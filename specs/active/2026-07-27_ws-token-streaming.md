# WS token 级流式推送 · 启动 Spec (IDEA_DOC)

> **创建日期**: 2026-07-27  
> **状态**: 讨论中  
> **负责人**: 待定

## 核心目标

实现 WebSocket token 级流式推送，让 Web UI 有实时打字动画。当前 MoonBit 聚合 StreamChunk 为单条 assistant_message，用户体验退化。

## 关键能力

- 实时推送每个 token 到 Web UI
- 支持打字动画效果
- 保持现有流式聚合逻辑
- 支持流式中断和恢复

## 明确不做

- **不做流式压缩**（原因：token 级数据量小）
- **不做流式加密**（原因：WS 已有安全机制）
- **不做流式缓存**（原因：实时性要求高）

## 关键决策（含为什么）

1. **决策 1**：在现有流式聚合基础上添加 token 级推送
   - **为什么**：不破坏现有逻辑，仅添加实时推送

2. **决策 2**：使用 WebSocket 推送 token
   - **为什么**：WebSocket 是实时通信的标准方案

3. **决策 3**：token 推送与内容聚合并行
   - **为什么**：确保实时性和完整性

## 验收维度

- [ ] Web UI 显示实时打字动画
- [ ] token 推送延迟小于 100ms
- [ ] 流式中断和恢复正常
- [ ] 现有流式聚合逻辑不受影响
- [ ] `moon check lib/web` 0 errors
- [ ] `moon test lib/web` 全部通过
