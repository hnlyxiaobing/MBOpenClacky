## 核心目标

实现 Fake Tool Call 检测器，检测部分模型在 content 中输出的 XML 工具调用（如 `<invoke name=`），并注入系统提示重试。当前 MoonBit 版本完全没有这个功能，导致 agent 静默退出。

## 关键能力

- 检测 5 种 XML 工具调用模式
- 检测到后注入系统提示重试
- 最多重试 2 次
- 记录检测到的 fake tool call 用于调试

## 明确不做

- **不做自动修复 XML**（原因：复杂度高，重试更可靠）
- **不做模型特定的检测规则**（原因：保持通用性）

## 关键决策（含为什么）

1. **决策 1**：使用正则表达式检测 XML 模式
   - **为什么**：正则表达式简单高效，适合检测已知模式

2. **决策 2**：检测到后注入系统提示重试，而非直接解析
   - **为什么**：重试让模型有机会正确输出工具调用

3. **决策 3**：最多重试 2 次
   - **为什么**：与 Ruby 行为对齐，避免无限重试
