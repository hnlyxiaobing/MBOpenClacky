# Product Help

## Purpose
Provide help and documentation about MBOpenClacky features, commands, configuration options, and best practices.

## Instructions
1. Identify the user's question or area of confusion
2. Search internal knowledge base and documentation first
3. If the answer is not found internally, search the web for:
   - Official documentation
   - Community resources
   - Related tutorials
4. Provide a clear, actionable answer
5. Include practical examples where helpful
6. Suggest related features or commands the user might find useful

## Output Format
- Direct answer to the question
- Relevant command or configuration example
- Step-by-step instructions if applicable
- Links to further documentation if available
- Related tips or best practices
