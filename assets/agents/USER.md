# User Guide

## How to Interact
- Give clear, specific instructions for best results
- Provide context about your project when starting new tasks
- Use slash commands (/skill-name) to invoke specific skills
- Say "remember X" to persist important information

## Available Profiles
- **coding**: Optimized for software development tasks
- **general**: Versatile assistant for all task types

## Tips
- Break complex requests into smaller steps
- Provide examples of desired output format
- Specify constraints upfront (language, framework, style)
- Use "explain" or "why" to get detailed reasoning
